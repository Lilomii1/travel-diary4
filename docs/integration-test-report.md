## Обнаруженные ошибки

1. При загрузке больших фото (>5 МБ) браузер может подвиснуть на 1–2 секунды.
   **Решение:** ограничение `maxSize = 1200px` в `photos.js`.

2. Подписи городов под маркерами иногда перекрывают друг друга.
   **Решение:** кнопка «🏷 Скрыть подписи».

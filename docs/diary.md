## Подробное описание ошибок

### Ошибка 1. `Storage is not defined`

**Симптом:** при открытии приложения — белый экран, 
в Console красная ошибка.

**Причина:** после разделения `app.js` на модули (день 5) 
файл `storage.js` не был подключён в `index.html`.

**Решение:** добавлена строка `<script src="storage.js"></script>` 
перед подключением `app.js`.

**Коммит:** `fix: подключён storage.js в index.html`

---

### Ошибка 2. `Auth is not defined`

**Симптом:** при нажатии «Зарегистрироваться» — ничего 
не происходит, ошибка в Console.

**Причина:** в `index.html` `storage.js` подключался **раньше** 
`auth.js`. А `storage.js` использует `Auth` внутри функций.

**Решение:** изменён порядок — `auth.js` теперь идёт первым.

**Коммит:** `fix: auth.js подключается раньше storage.js`

---

### Ошибка 3. Неверный формат даты

**Симптом:** ввожу `1 сентября 2026` — в карточке отображается 
`2026-9-1` вместо `2026-09-01`.

**Причина:** использовался `new Date(...).toISOString().split('T')[0]`, 
который убирает ведущие нули.

**Решение:** поле `<input type="date">` уже даёт строку в формате 
`YYYY-MM-DD` — достаточно взять значение напрямую.

**Коммит:** `fix: дата сохраняется в формате YYYY-MM-DD`

---

### Ошибка 4. Фото не сжимались

**Симптом:** при загрузке фото >5 МБ приложение подвисает, 
в Console — `Failed to execute 'drawImage' on 'CanvasRenderingContext2D'`.

**Причина:** canvas пытался отрисовать изображение **до** того, 
как оно полностью загрузилось.

**Решение:** добавлен обработчик `img.onload` **перед** установкой 
`img.src`.

**Коммит:** `fix: корректное сжатие фото через canvas`

---

### Ошибка 5. Статистика показывала 0 км

**Симптом:** есть 3 поездки, но поле «Км пройдено» = 0.

**Причина:** `renderStats()` вызывался **до** `renderTrips()`. 
Статистика считала по пустому массиву.

**Решение:** изменён порядок — `renderTrips()` идёт первым.

**Коммит:** `fix: статистика считается после загрузки поездок`

---

### Ошибка 6. Клик по карте не работал

**Симптом:** клик по карте не подставлял координаты в форму.

**Причина:** `window.__onMapClick` регистрировался **после** 
`TravelMap.init()`. Карта не находила обработчик.

**Решение:** обработчик регистрируется **до** инициализации карты.

**Коммит:** `fix: обработчик клика регистрируется раньше init`
